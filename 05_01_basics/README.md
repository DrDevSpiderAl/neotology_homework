## Task 4
Для гетерогенной среды виртуализации характерны следующие проблемы и недостатки:
- сложность администрирования (необходима высокая квалификация специалистов, которые должны разбираться во всех системах виртуализации, которые будут использоваться в проекте)
- сложность настройки политики безопасности (для каждой системы виртуализации необходимо будет выполнять отдельную настройку политик безопасности)
- интеграция (будет сложно настроить взаимодействие между виртуальными машинами в разных гипервизорах)
  Для того чтобы минимизировать риски и проблемы гетерогенной среды необходимо:
- использовать мультигипервизорную платформу, для автоматизации управления различными гипервизорами (управление из одной консоли)
- автоматизировать управления жизненным циклом ВМ
- создавать стандартизированные, защищенные шаблоны ВМ для всех гипервизоров
- сетменгировать сети гипервизоров, изолируя трафик ВМ с помощью виртуальных межсетевых экранов
- проводить периодический аудит гипервизоров, на предмет не действующих или не верно настроенных ВМ
   
  При возможности выбора, я бы не стал создавать гетерогенную среду.
